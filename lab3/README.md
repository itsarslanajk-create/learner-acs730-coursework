A real AWS account would use OIDC, so GitHub gets a fresh temporary login for each run and no keys
are ever stored.
AWS Academy blocks OIDC, so we store session keys as GitHub secrets instead, and if they leak the damage
is limited because they expire when the lab session ends and only work in this sandbox account.

Evidence of the automatic apply after a merge to main is in the evidence folder.
